# 💬 雑談お題 Bot（chat-topic-bot）

Discord コミュニティ「まぶさば」の雑談を活性化するための Bot です。
内蔵のお題バンク（100 件以上）からランダムにお題を出し、登録したチャンネルには
毎日決まった時刻に「今日のお題」を自動投稿します。メンバーがお題を追加することもできます。

## ✨ 機能

- **その場でお題**: `/topic` でランダムなお題を 1 つ投稿。直近に出たお題は避けるので、
  続けて使っても同じお題が繰り返し出ることはありません（プールを使い切ったら履歴をリセット）。
- **毎日の自動投稿**: `/topic-set` で登録したチャンネルに、毎日指定時刻（日本時間）に
  「今日のお題」を投稿。Bot が時刻後に起動した場合も、その日まだ投稿していなければ投稿します。
- **お題の追加**: メンバーが `/topic-add` でお題を追加可能。追加分は内蔵バンクとは別枠で
  保持され、そのサーバーの出題プールに含まれます。追加者名も記録されます。
- **状況確認**: `/topic-list` で投稿先の登録状況とお題の総数（内蔵／追加の内訳）を表示。

## 📝 コマンド

| コマンド | 権限 | 内容 |
| --- | --- | --- |
| `/topic` | 全員 | ランダムなお題を 1 つ投稿する |
| `/topic-set [time]` | サーバー管理（ManageGuild） | このチャンネルを毎日の投稿先に登録する。`time` は `21:00` の形式（日本時間、既定 21:00） |
| `/topic-add <text>` | 全員 | お題を追加する（最大 200 文字、サーバーあたり最大 100 件）。追加者は記録される。メンション記法を含むお題は追加できない |
| `/topic-remove <text>` | サーバー管理（ManageGuild） | 追加されたお題を削除する。本文（完全一致）または ID で指定する |
| `/topic-list` | 全員 | 登録状況とお題の総数を表示する（自分にだけ見える返信） |

お題はカテゴリ別（最近のこと / 好み・趣味 / もしも話 / 思い出 / ゲーム・音楽・アニメ /
食べ物 / 季節・日常）に用意されています。出題履歴はサーバーごとに管理されます。

## 🚀 セットアップ

1. [Discord 開発者ポータル](https://discord.com/developers/applications) で
   アプリケーションを作成し、Bot を追加します。**特権インテントは不要**です
   （Guilds のみで動作します）。
2. Bot をサーバーへ招待します。スコープは `bot` と `applications.commands`、
   権限は「メッセージを送信」があれば十分です。
3. `.env.example` を `.env` にコピーし、`DISCORD_TOKEN` と `CLIENT_ID` を
   設定します。開発中は `GUILD_ID` を設定するとコマンド登録が即時反映されます。
4. 起動します。コマンドは起動時に自動登録されます。

```bash
npm install
npm run build
npm start
```

登録だけを先に行いたい場合は `npm run deploy` が使えます。

### 環境変数

| 変数 | 必須 | 内容 |
| --- | --- | --- |
| `DISCORD_TOKEN` | ○ | Discord 開発者ポータルで作成した Bot のトークン |
| `CLIENT_ID` | ○ | アプリケーション（Bot）のクライアント ID |
| `GUILD_ID` | - | 設定すると、そのサーバーにだけコマンドを即時登録する（開発用） |
| `STATE_PATH` | - | 状態ファイルのパス。既定 `data/state.json` |

## 🎮 プレゼンス

全 Bot 共通のプレゼンス・サイクルを表示します（Playing、1 分ごとに交互表示）。

- `<Bot名> | 起動して <経過時間>`（経過時間は分粒度、起点はログイン完了時）
- `<Bot名> | 現在時刻 HH:MM JST`

値は次の分の境界時点のものを計算し、境界の 200ms 前に先行送信します
（Discord の伝播遅延と相殺するため）。位相は Unix 分の偶奇で決まるため、
全 Bot が同時に切り替わります。

## 📜 実行ログ

スラッシュコマンドの実行ごとに、標準出力へ 1 行のメタ情報を残します
（入力テキストの内容は記録しません）。毎日のお題投稿は対象外です。

```
[exec] <ISO時刻> cmd=<名前> route=slash guild=<ID> channel=<ID> user=<ID> result=<ok|error>
```

## 📝 お題の追加について

- `/topic-add` で追加したお題は、そのサーバー専用の追加枠として `data/state.json` に
  保存され、内蔵バンクと合わせて出題対象になります。
- 追加時は追加者の表示名とユーザー ID、追加日時が一緒に記録されます。
  不適切なお題が追加された場合は、サーバー管理者が `/topic-remove` で削除できます
  （`data/state.json` の `addedTopics` を手編集して再起動する方法でも削除できます）。
- メンション注入対策として、`@everyone` / `@here` / `<@...>` を含むお題は追加できず、
  Bot の全送信でもメンションは発火しない設定（`allowedMentions: { parse: [] }`）になっています。
- 内蔵バンクや追加済みのお題と完全に同じ文面は、重複として登録できません。
- 内蔵お題そのものを増やしたい場合は `src/topics.ts` のバンクへ追記してください。

## 📋 仕様メモ

- 状態（投稿先登録・追加お題・出題履歴・最終投稿日）は `data/state.json` に保存します。
  書き込みは tmp ファイル + rename で原子的に行います。
- 毎日の投稿チェックは 1 分間隔のループで行い、Asia/Tokyo 基準で判定します。
  最終投稿日を保持するため、再起動しても同じ日に二重投稿しません。
  ただし投稿は at-least-once です: 送信成功と「投稿済み」の保存の間にクラッシュすると、
  再起動後にその日のお題がもう一度投稿されることがあります（投稿の欠落より重複を
  許容する設計です）。
- 投稿先チャンネルが削除された・権限がない等、恒常的に投稿できない登録は
  自動で解除されます（一時的な失敗は解除せず、次回チェックで再試行します）。
- 状態ファイルが破損していた場合は、元ファイルを `state.json.corrupt-<時刻>` へ
  退避し、エラーログを残したうえで空の状態で起動します。
- 実行環境のタイムゾーンに依存しないよう、日付・時刻はすべて JST に変換して扱います。
- READY が 120 秒以上来ない場合はプロセスを終了し、pm2 の再起動に委ねます
  （READY ウォッチドッグ）。
